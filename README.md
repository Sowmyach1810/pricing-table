# Pricing Table

A responsive pricing table webpage featuring three subscription plans with pricing details and feature lists.

## Features
- Three pricing cards: Basic, Standard, and Premium
- Price details for each plan
- Feature lists
- Highlighted Popular plan
- Hover effects on buttons and cards
- Responsive layout for mobile and desktop

## Technologies Used
- HTML5
- CSS3

## How to Use
1. Open the Pricing Table webpage.
2. Compare the three available plans.
3. Review the features and prices.
4. Select your preferred plan using the button.
